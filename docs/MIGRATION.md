# แยกโครงการ Android — 15 พฤศจิกายน 2026

เมื่อเริ่มย้าย พื้นที่ทำงานเหลือเพียง checkout เริ่มต้น ไม่มีไฟล์ต้นแบบ APK กุญแจลงนาม หรือ local commits ของรอบนั้น

ซอร์สถูกประกอบกลับจากโค้ดและรายละเอียดที่บันทึกในบทสนทนา แล้วปรับเส้นทางบิลด์/แพ็กเกจให้เป็น repository แยก
จึงออก **0.1.1-prototype** พร้อมทดสอบและบิลด์ใหม่ ไม่ใช่สำเนาไบนารีหรือประวัติ Git ที่เหมือน 0.1.0 ทุกไบต์
ขอบเขตยังเป็น USB/PTP, เมนูภาษาไทย, อ่านค่า, ส่งชัตเตอร์ และรับ JPEG; ไม่มีฟีเจอร์กล้องใหม่ที่ผ่านการยืนยันบนเครื่องจริง

- ยังคง application ID `art.photoui.companion`; versionCode เพิ่มเป็น 2
- สร้างกุญแจ prototype ใหม่ เนื่องจากกุญแจเดิมไม่อยู่ใน workspace นี้
- ผู้ที่เคยติดตั้ง 0.1.0 อาจต้องถอนก่อนติดตั้ง 0.1.1; JPEG ที่บันทึกไปยังตำแหน่งที่ผู้ใช้เลือกไม่ใช่ไฟล์ cache ของแอป
- ไม่บรรจุกุญแจส่วนตัวหรือ Android SDK ใน Git/ซอร์ส ZIP
