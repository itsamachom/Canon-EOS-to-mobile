# ทดลอง 600D Companion 0.2.0

รุ่นนี้ยังไม่ยืนยันกับกล้อง/มือถือจริง แม้การทดสอบจำลองจะผ่าน ให้ทดสอบทีละส่วนด้านล่าง

## ติดตั้ง

1. ดาวน์โหลด APK 0.2.0 จากหน้าแรก GitHub แล้วกด Download raw file
2. Android 8 ขึ้นไป รองรับ OTG และอัปเดต System WebView/Chrome
3. ติดตั้งทับ APK 0.1.1 จาก repository ได้ในแง่ certificate/version: ตรวจว่าเซ็นกุญแจเดียวกันและ versionCode เพิ่มแล้ว ยังไม่ได้ทดลอง Android package installer จริง
4. ถ้าเคยลง 0.1.0 หรือไฟล์ที่เซ็นเองแล้วแจ้งลายเซ็นไม่ตรง ต้องถอนรุ่นเก่าก่อน ไฟล์ JPEG ที่คุณเลือกบันทึกไว้นอก cache ไม่ใช่ไฟล์ชั่วคราวของแอป
5. กด **ลองหน้าจอ** ตรวจเมนู 4 หน้า (เชื่อมต่อ/ถ่ายภาพ/ภาพในการ์ด/มอนิเตอร์) โหมดนี้ไม่มีการต่อ USB และไม่มีภาพถ่ายจริง

APK ใช้บนมือถือ ไม่ใช่ Firmware Update หรือ AUTOEXEC.BIN ของกล้อง

## ต่อกล้องและทดสอบถ่ายซ้ำก่อน

1. ใช้ OTG และสาย **USB Mini-B ที่ส่งข้อมูลได้** กล้อง/มือถือมีแบตเตอรี่ ใส่การ์ดที่มีพื้นที่
2. ตั้ง JPEG L หรือ RAW+JPEG L, ขับเคลื่อนภาพเดี่ยว, โหมด M, ชัตเตอร์ 1/125 และเลนส์ MF สำหรับเริ่มทดสอบ
3. หยุด ML Intervalometer/ระบบถ่ายอัตโนมัติ และปิดแอปควบคุมกล้องตัวอื่น
4. ต่อสาย เปิดกล้อง กดเชื่อมต่อ และอนุญาต USB ตรวจชื่อกล้อง/firmware
5. หน้าถ่ายภาพ: อ่านค่าเทียบกล้อง แล้วกดหนึ่งครั้ง รอข้อความพบไฟล์ใหม่/สถานะตอบกลับ ตรวจภาพบนกล้อง
6. ลอง **3 ครั้งต่อกันโดยไม่ถอดสาย** รอให้กล้องพร้อมทุกครั้ง ตรวจว่ามี 3 ภาพจริง
7. ลอง P/Tv/Av ตามต้องการ ต่อไปจึงลอง AF หากกล้องไม่ยืนยันโฟกัสและไม่ถ่าย ให้กลับ MF
8. ถ้ากดแล้วค้าง ให้ดูสถานะบนจอ ไม่กดซ้ำรัว ๆ กลับหน้าเชื่อมต่อกด **คัดลอกสถานะเพื่อแจ้งปัญหา** แล้วส่งข้อความพร้อมรุ่นมือถือ/Android

แอปไม่ retry ชัตเตอร์ให้อัตโนมัติ และไม่เปลี่ยนค่าแสงหรือปลายทางบันทึกให้เอง
กล้องต้องรายงาน card destination=2 และภาพเดี่ยว ไม่มี Bulb/การสั่งภาพนิ่งจากโหมด Movie ในรุ่นนี้

## ตารางภาพ / ดูชัด / ดาวน์โหลดหลายไฟล์

1. เข้า **ภาพในการ์ด** แอปอ่านชุดแรกให้เมื่อเข้าครั้งแรก จากนั้น Thumbnail จะทยอยโหลดเอง
2. ถ้ามีภาพมาก กดอ่านภาพเพิ่มเติม (แต่ละชุดตรวจไม่เกิน 80 handles ตามลำดับที่กล้องส่ง ไม่รับรองว่าเรียงตามวันเวลา)
3. แตะภาพหรือช่องเลือกเพื่อเลือกหลายภาพ กดเลือกทั้งหมด/ล้างได้ ไม่เกิน 80 ภาพต่อชุด
4. ปุ่มแว่นขยายจะ **รับ JPEG ต้นฉบับเต็ม** เพื่อดูชัด ไม่ใช้ Thumbnail มาขยายอีก กดพอดีจอ/100% เพื่อดูรายละเอียด
5. ความคมขึ้นกับ JPEG ที่บันทึกในกล้อง ตั้ง JPEG L ถ้าต้องการไฟล์ใหญ่ แอปไม่เพิ่มรายละเอียดหรือความละเอียดเกินต้นฉบับ
6. กดดาวน์โหลดภาพที่เลือก เลือกโฟลเดอร์เพียงครั้งเดียวต่อชุด Android บางรุ่นไม่อนุญาตเลือก root/Downloads โดยตรง ให้สร้างโฟลเดอร์ย่อย
7. แอปรับทีละไฟล์ตามคิว USB แสดงจำนวนสำเร็จ ชื่อไฟล์ และจำนวนล้มเหลว กดหยุดหลังไฟล์นี้ได้
8. เปิดไฟล์ที่บันทึกจากแอปดูภาพ Android ตรวจจำนวน/ความละเอียด/ขนาดไฟล์กับต้นฉบับในการ์ด

ไม่ลบภาพในการ์ด ไม่บีบอัด JPEG ใหม่ ถ้าปลายทางผิดพลาดจะหยุดชุดและแจ้งเหตุผล พยายามลบไฟล์ปลายทางที่เขียนไม่ครบ (ขึ้นกับ document provider)
รับ JPEG ≤64 MiB, Thumbnail ≤2 MiB; cache ในแอปจำกัด 128 MiB ไม่ใช่ที่เก็บถาวร

## Live View เป็นมอนิเตอร์

1. เชื่อมต่อแล้วเข้า **มอนิเตอร์ → เริ่ม Live View**
2. ถ้าอ่านค่า EVF ไม่ได้ ลองเปิด Live View บนกล้องก่อนแล้วเริ่มใหม่ จอกล้องอาจดับระหว่างส่งภาพออก USB
3. หมุนมือถือแนวนอน ใช้ปุ่มเต็มพื้นที่แอป เส้นตาราง และขยายจอ 1×/2× ได้ การขยายจอไม่ใช่การซูมเลนส์
4. ภาพนิ่งใน P/Tv/Av/M กดถ่ายภาพนิ่งจากหน้ามอนิเตอร์ได้ แอปพักการรับเฟรมระหว่างงาน และรับต่อเมื่อกล้องส่งเฟรมอีก
5. วิดีโอให้เลือกโหมดที่กล้อง เริ่มมอนิเตอร์ **ก่อน REC** และกดเริ่ม/หยุดบันทึกที่ตัวกล้อง
6. ยังไม่รับรองเฟรมขณะบันทึกทุกโหมด บางโหมดส่ง segment 9 แบบ non-JPEG ที่แอปรุ่นนี้แสดงไม่ได้ จะขึ้นข้อความ ไม่ใช้ภาพสาธิตแทน
7. เมื่อไม่มีเฟรมแสดงใหม่เกินประมาณ 2.5 วินาที จะขึ้น **ภาพค้าง** ไม่ได้หมายความว่ากล้องหยุดบันทึกวิดีโอ
8. fps บนจอเป็นเฟรมที่มือถือแสดง ไม่ใช่ fps ของไฟล์ MOV; USB มีความหน่วงและไม่ใช่สัญญาณ HDMI Full HD
9. กดหยุดรับภาพ/ออกจากหน้ามอนิเตอร์/พักแอปเพื่อหยุดรับเฟรม แอปพยายามคืนค่า output เดิม ไม่ส่งคำสั่งหยุด REC และไม่ปิด EVF mode หากสถานะ recording ไม่แน่ชัดหรืออยู่โหมด Movie

ถ้าระบบอ่านค่ากล้องไม่ได้หรือสื่อสารขาด ให้คัดลอกสถานะ ถอดสาย แล้วเชื่อมต่อใหม่ หาก session ค้างให้ปิด/เปิดกล้องตามปกติ
ยังไม่มี touch AF หรือสั่ง REC จากมือถือ

## ผลที่ช่วยรายงาน

- 0.2.0 ถ่าย 3 ครั้งติดกันได้หรือไม่ และโหมด/AF/MF ที่ใช้
- รูปแบบตารางและ Thumbnail โหลดได้ครบไหม ปุ่มดูชัดได้ JPEG ขนาดเท่าไร
- ดาวน์โหลด 2–3 ภาพเข้าโฟลเดอร์เดียวได้ครบหรือไม่
- Live View ภาพนิ่งได้ไหม โหมด Movie ก่อน/ระหว่าง REC มีภาพหรือขึ้นข้อความอะไร
- รุ่นมือถือ, Android version และข้อความจากคัดลอกสถานะ

ไม่ต้องส่ง serial number หรือภาพส่วนตัวเพื่อรายงานปัญหา
