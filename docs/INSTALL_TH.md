# วิธีทดลอง 600D Companion 0.1.1

ยังไม่ทดสอบกับมือถือและกล้องจริง ให้เริ่มจากโหมดสาธิตก่อน

## ติดตั้งบนมือถือ

1. ดาวน์โหลด APK จากหน้าแรก repository ลง Android 8 ขึ้นไป อัปเดต Android System WebView/Chrome ให้เหมาะกับเครื่อง
2. เปิด APK อนุญาตการติดตั้งจากแอปที่ใช้เปิดไฟล์หาก Android ขอ ไม่ต้องปิดระบบป้องกันทั้งเครื่อง
3. ถ้าเคยลง 0.1.0 แล้วขึ้นลายเซ็นไม่ตรงกัน ให้ถอน 0.1.0 ก่อน รุ่นนี้ใช้กุญแจ prototype ใหม่
4. เปิด **600D Companion** แล้วกด **ลองหน้าจอ**
5. ทดลองถ่ายภาพ → ภาพในการ์ด → อ่านรายการ → ดู/บันทึก ทั้งหมดเป็นข้อมูลจำลอง ไม่มีไฟล์กล้องให้บันทึก
6. กลับเมนูเชื่อมต่อ กดยกเลิกการเชื่อมต่อเพื่อออกจากสาธิต

## ต่อกล้องจริง

1. เตรียม OTG ตรงพอร์ตมือถือและสาย USB **Mini-B** ที่ส่งข้อมูลได้ (ไม่ใช่ Micro-B)
2. กล้องและมือถือมีแบตเตอรี่พอ ใส่การ์ดที่มีพื้นที่ ตั้ง JPEG หรือ RAW+JPEG
3. ตั้งกล้อง **M**, ชัตเตอร์ **1/125**, เลนส์ **MF**, ขับเคลื่อน **ภาพเดี่ยว**, ปิด Live View
4. ถ้ามี Magic Lantern ให้หยุด Intervalometer/ระบบถ่ายอัตโนมัติ ปิดแอปควบคุมกล้องอื่นบนมือถือ
5. ต่อ Android → OTG → สาย USB → 600D เปิดกล้อง กดเชื่อมต่อและอนุญาต USB
6. ตรวจชื่อกล้อง/firmware เปิดเมนูถ่ายภาพ กดอ่านค่า เปรียบเทียบกับกล้อง ค่าที่แปลไม่ได้แสดง 0x… ไม่เดาค่า
7. กดชัตเตอร์หนึ่งครั้ง รอให้กล้องหยุดเขียนการ์ด ตรวจไฟล์บนกล้อง แอปแจ้งเพียงรับคำสั่ง ไม่ยืนยันไฟล์เขียนเสร็จ
8. เปิดภาพในการ์ด กดอ่านรายการ เลือกดูภาพย่อ แล้วกดบันทึก รอรับ JPEG และเลือกที่เก็บบนมือถือ
9. เปิด JPEG ที่บันทึกด้วยแอปดูภาพ เทียบกับต้นฉบับ กดยกเลิกการเชื่อมต่อก่อนถอดสาย

## ข้อจำกัดและแก้ปัญหา

- แอปตรวจ USB VID 04a9 / PID 3218 และชื่อรุ่น 600D/T3i/Kiss X5 กล้องอื่นไม่ได้รับการยืนยัน
- อ่านสูงสุด 80 handles ท้ายตามลำดับที่กล้องส่ง ไม่รับรองการเรียงตามวันเวลา
- รับเฉพาะ JPEG ≤64 MiB, ภาพย่อ ≤2 MiB, metadata ≤8 MiB ต่อ dataset
- ไม่รับ RAW/MLV ไม่รับประกันการทำงานร่วมกับ ML ทุกบิลด์
- เงื่อนไขที่อ่านไม่ได้หรือ card destination ไม่ใช่ 2 จะหยุดก่อนส่งชัตเตอร์ ไม่เปลี่ยนปลายทางบันทึกให้เอง
- เปิดหน้าจอไว้ระหว่างรับภาพ ยังไม่มี foreground service สำหรับทำงานเบื้องหลัง
- USB read รอได้ถึง 15 วินาทีต่อครั้ง ถ้าสื่อสารขาดจะให้เชื่อมต่อใหม่ ไม่สั่งถ่ายซ้ำอัตโนมัติ
- หาก session ค้าง ให้ถอดสาย ปิด/เปิดกล้องตามปกติ และเปิดแอปใหม่
- ยกเลิกบันทึกมือถือไม่ลบต้นฉบับในการ์ด
- **APK สำหรับมือถือ ห้ามใช้กับ Firmware Update บนกล้อง**
