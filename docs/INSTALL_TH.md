# ติดตั้งและทดสอบ 600D Companion 0.4.0

1. ดาวน์โหลด APK จาก README → Download raw file บนมือถือ Android 8+ ที่รองรับ USB OTG
2. ติดตั้งทับ 0.1.1/0.2.0/0.3.0 ได้ในแง่ลายเซ็น/versionCode (ยังไม่ลอง Android installer จริง) ถ้าเป็นบิลด์ที่เซ็นคนละกุญแจ อาจต้องถอนรุ่นเดิม
3. เปิดแอปในแนวนอน หน้าจอควรคงแนวนอนเมื่อหมุนมือถือ ตรวจบนอุปกรณ์จริงอีกครั้ง
4. ต่อ OTG + สาย USB Mini-B ที่ส่งข้อมูลได้ เปิด 600D ใส่การ์ด กล้องและมือถือมีแบตเตอรี่
5. เชื่อมต่อและอนุญาต USB ตรวจรุ่น/firmware ปิดแอปควบคุมกล้องตัวอื่น
6. เข้า **มอนิเตอร์ → เริ่ม Live View** ถ้าอ่าน EVF ไม่ได้ ลองเปิด Live View ที่กล้องก่อน
7. เป้ารับคงที่ **12 fps** ไม่มีปุ่มเปลี่ยนเฟรมเรตหรือปรับค่าแสง ปรับโหมด/โฟกัส/ถ่ายภาพที่ตัวกล้อง
8. **Peaking** แสดงขอบสีแดงช่วยดูความคม แตะเปิด/ปิดได้ ไม่ใช่ autofocus หรือผลยืนยันโฟกัส
9. **Histogram** แสดงความสว่าง JPEG บนขวา แตะเปิด/ปิดได้ ไม่ใช่ RAW histogram และคำนวณจากทั้งเฟรมก่อนซูม
10. เส้นตาราง, จอ 1×/2× และเต็มจอช่วยดูภาพ ปุ่ม Back ออกจากเต็มจอ ขอบ peaking ขยายตามภาพ
11. วิดีโอ: หมุนโหมดและเริ่ม/หยุด REC ที่กล้อง เริ่มมอนิเตอร์ก่อน REC บางโหมดไม่ส่ง JPEG หรือหยุดส่งระหว่างบันทึก รุ่นนี้ยังไม่ยืนยันกับกล้องจริง
12. ภาพค้างเกินประมาณ 2.5 วินาทีจะซ่อน Peaking/Histogram และขึ้นป้าย ไม่ได้หมายความว่า REC หยุด
13. หน้า **ภาพในการ์ด** โหลด Thumbnail; แตะเลือกหลายภาพ ใช้แว่นขยายดู JPEG เต็ม ดาวน์โหลดแล้วเลือกโฟลเดอร์ครั้งเดียวต่อชุด ไม่ลบต้นฉบับ
14. ออกจากมอนิเตอร์หรือพักแอปเพื่อหยุดรับเฟรม แอปพยายามคืนค่า EVF เดิม หน้าจอกล้องอาจดับระหว่าง USB Live View

ทดสอบก่อนด้วย **ลองหน้าจอ** เพื่อดูเมนูและ overlay บนภาพจำลอง ไม่มีการต่อ USB หรือสร้างภาพถ่ายจริง
APK ลงมือถือ ไม่ใช่ Firmware Update ของกล้อง ไม่ต้องลง ML เพื่อใช้ Peaking/Histogram ของแอป

## ผลที่ช่วยรายงาน

- รุ่นมือถือ/Android และการคงแนวนอนเมื่อหมุน
- รับ/แสดง fps หลังเริ่มประมาณ 10 วินาที พร้อมเวลาอ่านเฟรม/หลังรับถึงแสดง
- Peaking ตรงขอบภาพไหมเมื่อโฟกัส/ซูม และ Histogram เปลี่ยนตามแสงไหม
- โหมดภาพนิ่ง/Movie ก่อนและระหว่าง REC มีภาพหรือข้อความใด
- Thumbnail/ดู JPEG เต็ม/ดาวน์โหลดหลายภาพทำงานหรือไม่

ถ้าสื่อสารค้าง ให้คัดลอกสถานะที่หน้าเชื่อมต่อ ถอดสายแล้วต่อใหม่ ปิด/เปิดกล้องตามปกติถ้าจำเป็น
ไม่ต้องส่ง serial number หรือภาพส่วนตัว ไม่มีผลทดสอบความเร็วหรือความแม่นยำบนกล้องจริงสำหรับ 0.4.0
