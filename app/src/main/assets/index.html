04 / FIELD GUIDE

พร้อมออกไปถ่าย

คู่มือสั้น ๆ สำหรับการทดลองครั้งแรก

อุปกรณ์และการเตรียม

  1. Android 8 ขึ้นไป ที่รองรับ USB Host / OTG และ WebView ที่อัปเดต
  2. อะแดปเตอร์ OTG ตรงกับพอร์ตมือถือ และสาย USB Mini-B สำหรับ 600D
  3. ใส่การ์ด เปิดกล้อง ตั้ง M, MF, ภาพเดี่ยว, JPEG หรือ RAW+JPEG และชัตเตอร์ 1/125 วินาที
  4. ปิดแอปควบคุมกล้องตัวอื่น กดเชื่อมต่อและอนุญาต USB
  5. อ่านค่ากล้อง → สั่งถ่ายหนึ่งภาพ → ภาพในการ์ด → อ่านรายการ → บันทึก JPEG

ขอบเขตรุ่นทดลอง

มี USB/PTP จริงสำหรับ 600D แต่ยังไม่ทดสอบกับกล้องและมือถือจริง รุ่นนี้อ่านค่าอย่างเดียว ไม่ปรับค่าแสง ไม่เปลี่ยน Picture Style ไม่มี Live View วิดีโอ หรือถ่ายอัตโนมัติ

ถ้ากล้องไม่ตอบสนอง ให้ถอดสาย ปิดแอปคู่แข่ง และเชื่อมต่อใหม่ อย่ากดชัตเตอร์ซ้ำขณะกำลังบันทึก หากใช้ ML ให้หยุด Intervalometer และระบบถ่ายอัตโนมัติก่อน
